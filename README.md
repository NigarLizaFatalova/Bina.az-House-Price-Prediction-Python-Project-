# Bina.az House Price Prediction (Python Project)

This project explores how machine learning can be applied to real-world housing data to predict property prices across Azerbaijan.  Using data collected from the Bina.az website, I built an end-to-end data pipeline that includes web scraping, data cleaning, analysis, and predictive modeling.

I used Python to collect and process thousands of property listings, cleaning messy and inconsistent data to prepare it for analysis. Through exploratory data analysis (EDA), I examined how variables such as location, number of rooms, and total area influence prices. The next step was to build machine learning models using Scikit-learn and XGBoost to predict housing prices more accurately.

Several algorithms were tested (Decision Tree, Random Forest, and XGBoost) to find the model that best captures the complex, non-linear relationships in the data. Among them, Random Forest and XGBoost showed the highest predictive performance, confirming that ensemble methods handle real-estate data variability best.  

This project demonstrates my ability to combine technical data skills with business understanding and turning raw web data into actionable insights about the local housing market.  
It also reflects a key data science workflow: collecting, cleaning, exploring, modeling, and interpreting data in a way that’s both analytical and practical.


### Tools and Libraries
Python (Jupyter Notebook), Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, XGBoost, BeautifulSoup
